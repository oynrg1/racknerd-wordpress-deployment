## 机房怎么选：国内访客和海外客户走的不是一条路

机房选错，同一台机器体验能差好几倍，这是建站最容易翻车的一步，而且 RackNerd 的机房开通之后不能改。

**国内访客为主，选洛杉矶 DC-02 或 DC-03。** 综合延迟和晚高峰稳定性最好，是国内访问的默认选项。洛杉矶 DC02 经常断货，看到有货就下手。圣何塞晚高峰略稳一些，可以作为备选；西雅图和圣何塞情况接近。

**客户在北美东岸或欧洲，选纽约。** 纽约机房的测试 IP 是 `192.3.81.8`，可以先自己 ping 一下再决定。社区实测数据大致是电信 256ms、移动 201ms、联通 224ms。移动和联通用户能接受，电信偏高一些，对延迟敏感就换洛杉矶。

**要清楚 RackNerd 走的是普通 BGP 线路，没有 CN2 优化。** 这是它价格低的原因之一。如果你的业务对大陆延迟极度敏感，比如低延迟流媒体或者实时交互，它整体不是最优解；做普通网站、博客、外贸站、开发测试环境，这一层完全够用。

**其他机房。** 新泽西、芝加哥、达拉斯延迟比西海岸高，定位和纽约类似。欧洲机房在伦敦、阿姆斯特丹、法兰克福、斯特拉斯堡、都柏林，只有访客在欧洲才值得选，国内访问要绕远。新加坡对亚太访客延迟低，但可选套餐少、库存紧。多伦多和蒙特利尔属于北美东岸的备选。

## 路线一：宝塔面板 + WordPress，适合要后台的情况

这是最主流的做法，全程可视化操作，SSH 只在装面板时用一次。

**第 1 步，SSH 登录并改密码。**

bash
ssh root@你的服务器IP
passwd


第一次连会提示 fingerprint 验证，输 `yes` 回车，粘贴邮件里的密码（终端不显示字符是正常的）。改密码建议 12 位以上，大小写字母加数字混排。

**第 2 步，装宝塔面板。** 按系统选命令：

CentOS：
bash
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh


Ubuntu：
bash
wget -O install.sh http://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh


装完终端会输出面板地址、账号和密码，先记下来。

**第 3 步，装 LNMP 环境。** 登录面板后在软件商店选 LNMP 组合：Nginx 1.20、MySQL 5.7、PHP 7.4、phpMyAdmin 5.0。这套组合跑 WordPress 没问题。编译安装要等十几分钟，别中断。

**第 4 步，建站并部署 WordPress。** 在面板里新建站点，域名填主域名加 www 两个；数据库账号用随机生成；打开强制 HTTPS，证书选 Let's Encrypt 免费签发。然后到软件商店的一键部署里选 WordPress，填域名和数据库信息，几分钟装完。最后去域名服务商加一条 A 记录，Host 填 `@`，Value 填服务器 IP，TTL 用默认，大约 10 分钟全球生效。

WordPress 安装界面里有两个细节：数据库主机保持 `localhost`，表前缀改成自定义字符，别用默认的 `wp_`；管理员邮箱用 Gmail 这类国际邮箱，国内邮箱收不到部分通知。

**第 5 步，安全加固。** 这五件事花不了多少时间，但能挡掉大部分自动化扫描：改掉宝塔默认的 8888 端口、开 SSH 密钥登录、装 Fail2ban、设置每日自动备份、在 PHP 设置里禁用 `passthru`、`system` 这类危险函数。主题用 Astra 或 GeneratePress 就够轻，插件装 WP Rocket 做缓存、RankMath 做 SEO。

系统版本上，老教程推荐 Ubuntu 20.04，那是 2025 年的说法。现在用 Ubuntu 22.04 或 Debian 11 更合适，软件源更新、支持周期更长，面板和 LNMP 组件都兼容。

## 路线二：纯静态站 + Apache，适合简历站和单页站

没有后台、不需要数据库的站点，走这条路更省事，一台 1GB 的机器绰绰有余。

用 AI 生成一份 HTML/CSS/JavaScript 的简历或落地页，复制代码存成 `index.html`，注意别存成 txt。本地双击打开，滚动检查各区块，拖动浏览器窗口宽度确认响应式没问题，再把姓名、经历、项目、联系方式换成自己的。

用 Bitvise SSH Client 连服务器，Host 填 IP，用户名 root，密码用邮件里那个。连上后终端和 SFTP 文件浏览器会同时打开。终端里装 Apache，装完在浏览器访问服务器 IP，看到默认的 Apache 页面就说明服务跑起来了。删掉默认页，在 SFTP 里进到 `/var/www/html/`，把 `index.html` 拖进去，刷新 IP，站点就上线了。

后续想接域名，还是加 A 记录指向服务器 IP。想加动画、嵌项目演示、放 GitHub 链接和可下载简历，直接改 `index.html` 再上传覆盖。

## 常见问题

**完全没接触过 Linux，能搞定吗？**
能。走宝塔路线的话，SSH 只在装面板那一步用一次，命令是官方给的，复制粘贴就行，之后全在浏览器里点。

**1GB 跑得动 WordPress 吗？**
跑得动，是底线。前提是别装太多插件，也别上 WooCommerce 这种重插件。加几个常用插件、开个缓存，日常访问量几百 PV 没问题。心里没底就直接上 2GB，一年多花 14 美元，PHP 进程能跑开，后台不卡。

**年付会不会有跑路风险？**
RackNerd 在 LowEndTalk 性价比榜单上连续多年出现，也上过 Inc. 5000 成长企业榜，机房二十多个，用户基数不小。预算型 VPS 偶有宕机和 IP 质量问题，这是整个价位段的共性。真介意的话，先买一台最便宜的年付跑几个月，比一次性押注更稳。

**IP 被墙了怎么办？**
开通后第一时间 ping 一下。连不上就开工单或者面板里换 IP，购买后 72 小时内首次免费，之后 $3/次。建站用途一开始就选洛杉矶 DC-02，被墙概率相对低。

**能升级配置吗？能按月付吗？**
能升级到高一档，重启生效，停机约一分钟，降级不行。按月计费的标准 KVM 套餐官网也有，单价折算比年付高不少，只适合短期试水。

**面板里的一键应用和宝塔选哪个？**
要中文界面、要国内教程多，选宝塔。只想快点把 WordPress 跑起来、不介意英文后台，ctrl 里的 CloudPanel 或 CyberPanel 一键装更快。
